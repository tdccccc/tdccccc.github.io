# 第 20 章 RL 扩展规律（ScaleRL）、超参配置与排障归因手册

<p class="chapter-summary">系统解读 ScaleRL 基于 40 万 GPU 小时总结的 S 形计算-性能扩展律，学会用小实验预测大训练并分辨“提效技巧”与“提上限技巧”，沉淀核心超参数量级指南与 9 大监控指标的故障归因树。</p>

跑大模型 RL 最昂贵的浪费，莫过于拍脑袋同时改五个超参和算法技巧，砸进去几万 GPU 小时后，既说不清到底是哪个改动真正起作用，也分不清这个技巧只是“前期涨得快了一点”还是真的“把天花板抬高了”。

本章作为全书的工程收官，把前三篇的算法直觉与第六篇的系统根因全部凝练为三套可立即复用的工作方法：**用 ScaleRL 扩展律指导实验设计、按数量级定好核心超参、用 9 项监控指标构建故障归因闭环**。

## 20.1 RL 的扩展规律：ScaleRL 与 S 形饱和曲线

- **出处**：Khatri 等（Meta 等），*The Art of Scaling RL Compute for LLMs（ScaleRL）*，2025-10，arXiv `2510.13786`。

虽然发表于 2025 年末，ScaleRL 确立了 2026 年工业界科学评估 RL 配方的通用方法论。作者耗费超过 **40 万 GPU 小时**做了大规模受控消融，得出一个与预训练截然不同的核心定律：

在预训练里，测试集交叉熵损失随算力呈幂律（Power Law）持续下降；而在可验证奖励（RLVR）的强化学习里，验证集通过率 $R_C$ 随训练计算量 $C$ 近似服从一条 **S 形饱和曲线（Sigmoidal Scaling Law）**：

$$
R_C = R_0 + \frac{R_\infty - R_0}{1 + \big(C_{\text{mid}} / C\big)^{B}}
$$

（注：原文将渐近上限记作 $A$，本书改用 $R_\infty$ 以避免与优势函数 $A_t$ 冲突。）

五个参数各自对应清晰的工程物理含义：
- $R_0$：RL 起点（基座或冷启动模型初始通过率）；
- **$R_\infty$**：算力趋于无穷时的**渐近性能上限（天花板）**；
- $C_{\text{mid}}$：拿到一半总收益 $(R_0 + R_\infty)/2$ 所需的**半程计算量**；
- $B$：曲线爬升的**陡峭度（计算效率）**。

### ScaleRL 揭示的两条颠覆性工程结论
1. **小实验外推大训练**：只要在较小算力窗口测出曲线早期拐点，拟合出 $(R_\infty, C_{\text{mid}}, B)$，就能较准确地预测放大 $10\times$ 算力后的最终通过率，避免盲目开跑超长实验；
2. **绝大多数流行技巧只改效率 $B$，不改天花板 $R_\infty$！**
   - 异步调度、过滤零方差组、动态停止重采已掌握简单题等技巧主要降低 $C_{\text{mid}}$、提升效率，让你花更少 GPU 小时撞到上限；
   - 而<strong>损失函数选择（CISPO 式优于 DAPO 式）</strong>与<strong>输出头使用 FP32 精度计算 logits</strong>，则实实在在地<strong>抬高了渐近天花板 $R_\infty$</strong>！

综合全部受控实验，论文给出了经过大规模验证的 **ScaleRL 推荐配方**：
- **系统**：PipelineRL 异步流水线训练；
- **目标与精度**：**CISPO** 损失 + 输出头 **FP32 logits**；
- **归一化与聚合**：提示级损失平均 + Batch 级优势归一化；
- **数据效率**：过滤零方差组 + 不再重复采样已经很容易（高通过率）的题目。

> **边界提示**：ScaleRL 的实验全面覆盖数学/代码等可验证奖励任务；在开放式学习型 RM 或多轮长程 Agent 环境上，具体饱和曲线形态仍需结合奖励作弊拐点综合判断。

## 20.2 关键超参数量级速查指南

开始一次新的后训练 RL 实验时，先把下面七个核心超参落在经过验证的安全数量级上，再做单变量微调：

| 超参数 | 典型安全取值 | 底层机理与调参红线 |
| --- | --- | --- |
| **学习率（LR）** | **$1\times 10^{-6}$ 量级**（常数或短暂线性预热） | 比 SFT（常为 $1\text{–}5\times 10^{-5}$）低整整一个数量级以上；RL 梯度信噪比远低于监督学习，LR 稍大就极易触发梯度爆炸或熵崩 |
| **组大小 $G$** | **$8\text{–}64$**（推理 RLVR 常见 $8\text{–}16$） | $G$ 越大，组内均值基线越准、零方差全错组越少（对难题尤其关键），代价是 Rollout 成本线性上升 |
| **裁剪 $\varepsilon$** | Token 级 **$0.2$**（DAPO：$0.20 / 0.28$）<br>GSPO 序列级 **$10^{-4}$ 量级** | 千万别把 token 级的 $0.2$ 直接填进 GSPO！序列几何平均波动小两个数量级，填 $0.2$ 等于彻底取消裁剪 |
| **KL 系数 $\beta$** | RLHF 学习型 RM：**$0.01\text{–}0.05$**<br>RLVR 规则验证：**$0$ 或 $10^{-3}$ 级** | 奖励代理越不可靠越需要强 KL 拴住；RLVR 需大幅改变推理分布，常设 $\beta=0$ |
| **采样温度 $T$** | **$1.0$**（探索不足时可尝试 $1.0\text{–}1.2$） | **铁律**：若 $T \ne 1.0$，计算 $\pi_{\text{old}}$ 与 $\pi_\theta$ 的对数概率必须同样用 $T$ 缩放 logits，否则比率从第 0 步起即错位 |
| **最大生成长度 $L_{\max}$** | 依任务：常规 $4\text{k–}8\text{k}$；长 CoT **$32\text{k–}128\text{k}$** | 监控截断比例（Clipped/Truncated Ratio）；若超过 $10\%\text{–}15\%$，需启用 DAPO 超长缓冲塑形或按课程分阶段放宽 |
| **Off-Policy 步数 $d$** | 同步 $1$（或 inner epoch $1\text{–}2$）；异步 **$1\text{–}8$** | 越大 GPU 吞吐越高，但越强依赖第 18 章的 TIS / IcePop / Mu-GRPO 与 CISPO 稳态护航 |

## 20.3 监控仪表盘与故障归因树

大模型 RL 绝不能只盯着一条“Training Reward”盲跑。生产级实验面板至少必须同时铺开 **9 项核心监控指标**——每项指标异常都指向明确的底层病灶：

| # | 监控指标 | 健康曲线表现 | 异常信号与优先排查方向 |
| --- | --- | --- | --- |
| 1 | **训练奖励均值** | 平稳渐进爬升 | **毫无过渡突然跃升**：极高概率找到了奖励作弊捷径！立刻肉眼抽查高分回复 |
| 2 | **验证集 $\text{pass@}1$ 与 $\text{pass@}k$** | 两者同步抬升 | **$\text{pass@}1$ 升但 $\text{pass@}k$ 跌**：多样性正在剧烈萎缩，警惕过度锐化或熵耗尽 |
| 3 | **策略熵 $\mathcal{H}$** | 缓慢温和下降并稳在非零平台 | **前百步骤降趋零**：熵坍缩（查 Clip-Higher / 温度）；**突然直线飙升**：输出已崩溃吐乱码 |
| 4 | **$\mathbb{D}_{\mathrm{KL}}[\pi_\theta \,\|\, \pi_{\text{ref}}]$** | 随步数平滑缓慢增长 | **指数级激增**：步幅过大或奖励异常，立刻核查 LR、$\beta$ 与优势归一化尺度 |
| 5 | **平均长度与截断比例** | 随题难度自然演化、截断率低 | **错答长度暴涨**：检查 GRPO $1/\vert y_i\vert$ 偏差或死循环复读；**截断率高**：放大 $L_{\max}$ 或加超长塑形 |
| 6 | **裁剪比例（Clip Fraction）** | 保持极低且平稳（常 $<1\%\text{–}5\%$） | **持续攀高**：LR 过大、inner epoch 太多、异步陈旧度 $d$ 过高，或存在未修正的训练-推理不一致 |
| 7 | **零方差组比例（Zero-Var Groups）** | 维持在中低区间 | **过高（如 $>50\%$）**：数据难度与模型当前能力失配（全对或全错太多），启用动态采样或刷新课程数据 |
| 8 | **$\lvert\log\pi_{\text{train}} - \log\pi_{\text{infer}}\rvert$** | 贴近 $0$ 且全程平稳 | **随步数逐步抬头**：训练-推理不一致累积，常是数值崩溃前数小时的精确警报（上 TIS / IcePop / R3） |
| 9 | **全局梯度范数（Grad Norm）** | 平稳无剧烈毛刺 | **频繁出现巨型尖峰**：数值不稳定、异常长尾样本或 MoE 路由翻转（通常与第 8 项同步报警） |

## 全书结语：走向更稠密信号与真实环境的后训练时代

回头鸟瞰这 20 章走过的长路，大模型后训练强化学习的演进脉络异常清晰：
- **底层不变**：一切方法始终围绕“在自身分布上最大化期望奖励、同时以 KL 或信赖域守住稳定”这一条统一目标展开；
- **算法跃迁**：我们从沉重的四模型 PPO，走到轻巧离线的 DPO，再到释放 RLVR 推理红利的 GRPO 及其修正家族（Dr.GRPO / DAPO / GSPO / CISPO），直至 2026 年改写目标函数与信号密度的 MaxRL、GDPO、SDPO 与在线蒸馏 OPD；
- **疆域外扩**：任务从单轮对话与数学解题，迈向了百轮工具交互、代码沙箱与并行多智能体编排；瓶颈也随之从单机算法公式，延伸至异步分离系统、训练-推理数值一致与高并发隔离环境。

还有五个尚未完全盖棺定论的开放前沿将持续塑造未来数年的研究：**RL 拓展能力边界的极限在哪？不可验证开放任务的终极奖励怎么评估？千步长程 Agent 的信用分配与低成本环境如何突破？RL 与在线蒸馏的最佳动态配比是什么？以及如何在强优化压力下根治会泛化的奖励作弊？**

如果你想继续深入某一专项，可前往[进阶专题库](/books/llm-rl/topics/paper-notes)查阅论文口径档案、多模态 RL、测试时计算与经典深度 RL 脉络；动手编码与排障时，随时翻阅[参考手册与工具箱](/books/llm-rl/toolkit/debugging-checklist)中的速查表与最小 PyTorch 实现。
