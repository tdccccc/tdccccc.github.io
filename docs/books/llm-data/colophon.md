# 来源、口径与许可

<p class="chapter-summary">说明本书在 Tdccccc's Atlas 四部曲中的收官闭环定位、一手论文与开源数据集引用口径、2026 年前沿边界，以及 CC BY 4.0 知识共享许可。</p>

## 一、定位与四部曲工程闭环

《LLM 与 Agent 数据工程：原理、配方与迭代飞轮》是 **Tdccccc's Atlas** 的第四本系统技术专著，与前三部专著体例严格对齐，共同完成大模型全栈研发的 **「数据燃料 × 后训练引擎 × 推理底座 × 评测标尺」四维闭环**：

- **第一本** [《LLM 推理工程：原理与方法》](/books/llm-inference/)：解决“跑得快、算清显存与算力账”，同时为本书第 21 章的大规模离线批合成提供吞吐与成本底座；
- **第二本** [《LLM 强化学习：原理与后训练实践》](/books/llm-rl/)：解决“训得强、稳住策略梯度与多轮 RL 系统”，而本书第三、五篇直接供给它所需的 SFT、Rubric、RLVR 题库与 Agent 轨迹燃料；
- **第三本** [《LLM 与 Agent 评测：原理、基准与工程实践》](/books/llm-eval/)：解决“测得准、拆开模型与脚手架、落到企业黄金集”，本书第 3 章与第 23 章与其形成训练侧去污与双轨物理隔离的严密咬合；
- **第四本（本书）**：把散落在预训练、后训练、多模态与 Agent 一线的“数据暗知识”系统工程化，完整回答数据**怎么获取、怎么清洗合成、怎么资产化积累、怎么安全迭代**四个核心问题。

全书采用 **6 篇 25 章** 布局，既保留了预训练（16%）与后训练（16%）的扎实底座，又将**多模态数据全栈（12%）**升格为独立篇目，并把**Agent 数据工程（24%）**与**规模化合成、企业资产化与生产飞轮（20%）**作为核心加厚高地。

## 二、资料选用与数字口径原则

1. **一手技术报告与开源配方优先**：书中涉及的经典语料、清洗管线与数据方法（如 Data-Constrained Scaling、FineWeb / FineWeb-2、DCLM、Dolma / Olmo-2、Nemotron-CC、DoReMi / RegMix、DEITA、Tulu-3、OpenThoughts、DataComp / OBELICS / FineVision、SWE-smith / SWE-gym、ToolBench / APIGen、OSWorld 等）与分布式基础设施（Datatrove、Ray Data、NeMo Curator、Lance、LakeFS）均追溯至一手论文或官方文档，并在 [专题 A：经典开源数据集与基座配方档案](/books/llm-data/topics/dataset-archive) 集中汇总口径。
2. **时间截点与前沿边界**：本书内容整理截至 **2026 年 11 月**。模型版本号与单次算力报价随时变动，正文着重沉淀**跨代际有效的第一性原理、留存漏斗账本、数据结构规范、防坍缩机制与排障归因方法**。
3. **教学算例口径声明**：正文及交互实验中的集群洗数报价、人工精标单价与合成通过率（如第 1、7、16、21 章成本账）均取 2026 年工业界代表性区间作为教学算例，用于建立清晰的数量级直觉，实际落地请代入本团队真实报价与实测 Yield 核算。
4. **全局符号唯一源**：全书 25 章与 4 篇专题强制遵循 [核心公式、数据账本与成本速查卡](/books/llm-data/toolkit/formulas-and-ledgers)，严格区分唯一语料量 $D_U$、总训练预算 $D_{\text{tok}}$、重复轮数 $E$ 与 LSH 每带行数 $r_{\text{lsh}}$，避免跨社区符号撞车。
