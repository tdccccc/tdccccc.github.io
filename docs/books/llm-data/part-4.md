# 第四篇：多模态数据工程全栈

<p class="chapter-summary">打通图像、复杂文档、视频与端到端全双工语音的数据工程链路：用密集重打标替代噪声网页 Alt-text，算清音视频解码与分片存储 I/O 账，攻克视觉长思维链（Visual CoT）与跨模态混配防纯文本遗忘难题。</p>

## 本篇导览

2025–2026 年的前沿模型与 Agent 早已全面迈入原生多模态与全模态（Omni）时代——企业文档里藏着表格与工程图纸，GUI Agent 需要读懂高分屏幕截图，客服与车载助手要求毫秒级全双工语音交互。多模态数据工程不仅带来十倍以上的存储与解码 I/O 挑战，还面临**图文错配、时间轴漂移、小字模糊丢失以及跨模态训练拖垮纯文本推理**等特有难题。

第 12 章深讲视觉-语言（VLM）基础数据：网页图文过滤、交错文档（Interleaved）上下文保留、密集重打标（Recaptioning）及高保真 OCR/图表/文档解析合成工厂；第 13 章打通视频镜头切分、时空采样与视听对齐、全双工语音数据构造及二进制大对象 I/O 优化；第 14 章聚焦视觉长思维链（Thinking with Images）与 VLM-RLVR、图像/视频生成偏好数据，以及跨模态混配保纯文本能力的阶段化配方。
