# 专题 D：垂直行业（金融 / 医疗 / 法律 / 工业）私有数据实战

<p class="chapter-summary">把通用数据工程方法论落进真实垂直业务深水区：逐一拆解金融、医疗、法律与工业制造四大行业的私有文档多模态解析陷阱、知识图谱辅助高保真合成、领域退火与混配经验比例，以及不可逾越的合规与安全红线。</p>

企业落地垂直大模型与行业 Agent 时，最大的挫败往往不是“缺数据”，而是**手握数百万份私有财报、病历、判例或工艺图纸，训完之后却发现模型要么幻觉瞎编数字、要么把通用推理能力训废，或者卡在法务合规评审无法入库**。与公开互联网洗数不同，垂直行业数据体量通常在数亿至数百亿 Token 量级，核心矛盾从“规模清洗”彻底转向**极高解析保真度、严格时效与权威层级管理、以及零容忍合规脱敏**（呼应 [第 22 章](/books/llm-data/chapters/chapter-22) 与 [第 24 章](/books/llm-data/chapters/chapter-24)）。

## D.1 四大行业私有数据解析陷阱与资产化 Playbook

### 1. 金融（Finance）：财报、研报、投研表格与合规口径

- **高频解析陷阱**：① **跨页合并单元格与嵌套表头**（利润表/现金流量表跨页断行后，“归母净利润”错位挂到上一年列下）；② **单位与正负号隐形丢失**（表头右上角写着“单位：百万元”或括号 `(1,234)` 表示负数，普通 OCR 剥离页眉后导致数值放大百万倍或符号翻转）；③ **图表与脚注脱节**（K 线/柱状图数据标签及表格末行“注 3：含非经常性损益”在切片时被截断）。
- **数据治理与合成打法**：强制以 **HTML / 结构化 Markdown Table + 表头上下文继承** 保存财务报表，将“报表币种、单位、审计口径、报告期”写入每一条切片元数据；用 **Python 财务计算验算器** 对合成的多步财务比率/同比环比问答执行确定性校验；严格打上**公告发布时间戳（Point-in-Time）**，按时间切分训练与回测评测集，彻底杜绝**前视偏差（Look-ahead Bias）**。

### 2. 医疗（Healthcare）：电子病历、医学影像与循证指南

- **高频解析陷阱**：① **非标准院内缩写与上下文歧义**（如同一英文缩写在不同科室指向截然不同的疾病或检验项）；② **影像与病理报告脱节**（DICOM 医学影像的窗宽/窗位丢失、原始文件头暗藏患者姓名与检查号）；③ **过时教材与最新循证指南冲突**（旧版教材用药方案已被最新 NCCN / 中华医学会临床指南废止，混训导致致命用药幻觉）。
- **数据治理与合成打法**：遵循 HIPAA Safe Harbor（18 类标识符）及国内《个人信息保护法》医疗敏感信息规范，实施**文档文本 + DICOM Header + 胶片角落烧录文字三路联动的 <a class="term-ref" href="/books/llm-data/glossary#pii_redaction" title="检测文本/图像/音频中个人敏感信息并保持语义一致假名化的管线">PII 脱敏</a>**；建立**证据等级权重库**（最新循证指南与多中心 RCT > 专科教材 > 脱敏典型病历 > 网络问诊语料），高危诊疗建议强约束附加“不确定时拒答并转诊提示”。

### 3. 法律（Legal）：法规层级、裁判文书与精确引用归因

- **高频解析陷阱**：① **法条效力状态漂移**（把已废止法条或旧司法解释当成现行法律援引）；② **层级冲突与地域适用混淆**（地方法规、部门规章与上位法条款边界不清）；③ **实名信息泄露与伪造判例**（脱敏时简单把所有名字都替换成 `[NAME]`，导致原告、被告、第三人与担保人在多页起诉状中指代彻底混乱）。
- **数据治理与合成打法**：采用**实体一致假名化（Consistent Pseudonymization）**（同一文书内统一映射为“自然人甲/公司 A”），保留严密的法律主客体关系；所有法律语料入库必挂三维结构化元数据 `效力层级 / 颁布机构 / 现行状态（有效|修订|废止）`；在 SFT 与 RAG 数据中强制执行句级 <a class="term-ref" href="/books/llm-data/glossary#citation_grounding" title="要求关键事实主张严格绑定到具体检索段落与法条编号的归因机制">引用归因</a>，每条生成结论必须经正则与法库索引自动校验法条编号与正文一致，彻底封堵“编造判例号”。

### 4. 工业与制造（Industrial / Manufacturing）：CAD 图纸、SOP 手册与故障日志

- **高频解析陷阱**：① **高分辨率工程图细微特征塌陷**（A1/A0 级 CAD 蓝图与电路原理图含密集公差、焊点与引线编号，粗暴缩放至 $448\times 448$ 后文字全糊，必须启用 <a class="term-ref" href="/books/llm-data/glossary#dynamic_resolution" title="按原图长宽比自适应切分图块并保留全局缩略图的高分处理机制">动态分辨率切片</a> 并联合向量 CAD/SVG 矢量解析）；② **多模态排障信息割裂**（设备维护 SOP 图文手册、BOM 物料表、SCADA 传感器异常曲线与历史维修工单散落在不同系统）。
- **数据治理与合成打法**：以“设备型号 → 故障代码 → 传感器异常特征 → SOP 排查分支 → 根因与备件替换”为主线，将静态 PDF 手册与历史真实维修闭环工单对齐，批量合成带分步核查断言的**排障诊断 Agent 轨迹**（联动 [第 16 章](/books/llm-data/chapters/chapter-16) 与 [第 18 章](/books/llm-data/chapters/chapter-18)）。

## D.2 知识图谱辅助合成与领域退火混配配方

垂直领域原始文档往往“知识密度极高、但缺乏多跳推理问答与任务指令形态”。直接把原始 PDF 切片喂给模型做 SFT 效果通常很差，工业界验证最稳妥的两步增效工艺如下：

1. **知识图谱（KG）辅助多跳问答与反事实合成**：
   - 先从已清洗文档中抽取领域本体三元组（如“财报科目→勾稽关系→风险条款”、“疾病→一线用药→肝肾禁忌证”、“故障码→前置检查项→备件号”），构建轻量行业知识图谱；
   - 在图谱上随机游走采样 **2–3 跳子图路径**，将原始证据段落一并交给强模型合成复杂跨文档推理题、边界条件反例（如“若患者合并重度肾功能不全，该方案应如何调整”）及**拒答样本**（刻意抽走关键证据要求模型明确声明信息不足），再以原段落为锚做自动化事实一致性核验。
2. **领域退火与 SFT 防遗忘混配参考比例**：
   垂直私有数据切忌“100% 纯领域语料暴力灌注”，否则极易触发 [第 11 章](/books/llm-data/chapters/chapter-11) 的 <a class="term-ref" href="/books/llm-data/glossary#negative_transfer" title="上调某类数据导致模型在通用指令或推理上显著回退的现象">负迁移与灾难性遗忘</a>（模型背熟了行话却丧失基本逻辑与指令遵循能力）。推荐基准配方如下：

| 训练阶段 | 垂直私有高质量语料占比 | 通用锚定回放语料占比 | 关键工程策略 |
| --- | --- | --- | --- |
| **领域继续预训练 / <a class="term-ref" href="/books/llm-data/glossary#mid_training" title="预训练末段学习率衰减阶段的高密度数据退火">退火</a>** | **20%–35%**（高保真文档 + 领域教科书改写） | **65%–80%**（通用百科、代码、数学推理与原底座分布） | 低学习率余弦退火；私有高质语料重复不超过 **3–4 轮**（参照 Data-Constrained Scaling） |
| **领域 SFT / 推理冷启动** | **30%–50%**（KG 多跳 QA + 专家精标 + 行业工具/RAG 轨迹） | **50%–70%**（通用指令、通用长思维链、拒答安全样本） | 严控单条格式多样化，防止过拟合单一报表或工单模板 |
| **领域 RLVR / Rubric-RL** | **60%–80%**（带数值/法条/SOP 规则验证器与专家 <a class="term-ref" href="/books/llm-data/glossary#rubric" title="将开放任务拆解为可核验原子检查项与扣分红线的评分细则">Rubric</a>） | **20%–40%**（通用推理与通用指令遵循守门题） | 用确定性规则卡死数值误差、引用错位与越权回答，同时盯紧通用回归集掉点 |

## D.3 垂直多跳合成样本的确定性验真 Schema 示例

  "sample_id": "fin-2026q1-multihop-00419",
  "domain": "finance",

## D.4 四大行业数据治理与合规红线速查表

| 行业 | 核心敏感数据形态 | 不可逾越的合规与安全红线 | 数据入库必过门禁 |
| --- | --- | --- | --- |
| **金融** | 客户账户/资产流水、未公开财报、内幕交易线索 | 严禁客户 PII 出域；禁止训练无依据个股荐股承诺；严格防前视时间泄漏 | 时间戳隔离审计 + 账号/身份证全量脱敏 + 财务勾稽计算校验 |
| **医疗** | 患者病历、医保号、DICOM 影像与基因数据 | 患者隐私零泄漏（文本+影像双脱敏）；严禁输出致死剂量/禁忌用药幻觉 | 18 项标识擦除核验 + 临床专家双盲复核 + 循证指南版本号绑定 |
| **法律** | 个人身份、商业秘密条款、未公开卷宗 | 严禁编造不存在法条/判例；严禁混用已废止条款；当事人跨实体隐私隔离 | 一致假名化检测 + 现行有效法库自动对账 + 句级引用 100% 匹配 |
| **工业** | 核心工艺配方、图纸 CAD 知识产权、设备控制指令 | 严防商业机密外泄至外部公有云 API；严禁生成绕过设备安全联锁的操作指令 | 私有化离线合成部署 + 图纸水印/项目编号擦除 + 安全联锁规则拦截 |

::: tip 私有数据价值最大化的顺序决策
当垂直领域私有文档不足百万字或规则高度动态变化（如每日更新的监管条款与产品价格）时，**切忌急着做继续预训练**——优先把预算投入高保真文档解析 + 多模态 RAG 证据链 + 带引用归因与工具调用的 Agent 轨迹微调；只有当行业具备大量独有专业术语体系、复杂结构化知识密度极高且相对稳定时，才启动领域 Mid-training 退火。
:::
