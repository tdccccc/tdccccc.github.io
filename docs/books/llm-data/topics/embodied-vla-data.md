# 专题 C：具身智能（VLA）与世界模型数据工程速览

<p class="chapter-summary">将第四篇多模态与第五篇 Agent 数据工程自然延伸至物理具身前沿：拆解真机遥操作数据采集（OXE / DROID / AgiBot）、Sim-to-Real 仿真合成与域随机化、连续动作 Token 化（Bin 量化 vs FAST 频域编码）、人类第一视角视频预训练与物理运动学清洗铁律。</p>

如果说 [第 19 章](/books/llm-data/chapters/chapter-19) 的 GUI Agent 把模型带入了数字屏幕里的二维交互世界，那么**视觉-语言-动作模型（VLA, Vision-Language-Action）与物理世界模型（World Models）**则将“感知→决策→执行→观测”闭环推进到了三维物理空间。两者在数据工程底层共享同一套多模态 <a class="term-ref" href="/books/llm-data/glossary#trajectory_ir" title="跨任务与多模态观测的标准化轨迹数据结构">Trajectory IR</a> 与 <a class="term-ref" href="/books/llm-data/glossary#environment_as_data" title="把可重置、带确定性状态断言的交互环境作为一等数据资产管理">环境即数据</a> 思想，但物理世界的不可逆性、硬件本体差异与毫秒级高频控制，使具身数据成为当前 AI 行业稀缺度与采集单价最高的数据金字塔尖。

## C.1 具身数据为何比文本与 GUI 数据难一个数量级

| 维度 | 网页 / GUI Agent 轨迹 | 具身智能（VLA）物理轨迹 | 对数据工程的直接约束 |
| --- | --- | --- | --- |
| **动作空间** | 离散点击/按键/工具 JSON（0.2–1 Hz） | 7-DoF/双臂 14-DoF 关节角、末端位姿与夹爪力矩（10–50 Hz 连续控制） | 须处理高频连续序列平滑度、动作分块（Action Chunking）与专用 Token 化 |
| **状态重置成本** | Docker / VM 毫秒级回滚快照 | 真实物体打翻/耗材消耗需人工逐次复位 | 真机吞吐受物理时钟锁死，必须依靠**真机示范 + 仿真增广 + 人类视频**三路混合 |
| **本体异构性** | 浏览器 DOM / Ubuntu 桌面高度统一 | Franka、UR5、ALOHA、人形双臂等自由度、相机安装位与坐标系迥异 | 强依赖跨构型统一 Schema 与相对末端位姿/通用视觉表征对齐 |
| **多模态同步** | 单张截图配一次工具返回 | 多目 RGB-D（腕部 + 第三视角）+ 关节本体感知 + 触觉力传感器 | 严控微秒级硬件时间戳对齐，微小帧延迟即导致策略高频抖动或撞击 |

## C.2 真机遥操作采集谱系与统一湖仓格式

真机遥操作（Teleoperation，通过主从机械臂 ALOHA、VR 手柄、动作捕捉手套或外骨骼采集人类示范）是目前物理接触精度最高、但单条成本最昂贵（通常数美元至数十美元/条）的黄金数据源：

- **Open X-Embodiment（OXE，Google DeepMind 等）**：汇聚 22 种不同机器人本体、60 个子集与超 100 万条真实轨迹，确立跨本体联合预训练范式（RT-X / Octo / OpenVLA），采用统一的 **RLDS（TFDS）** 序列格式封装 `observation / action / language_instruction`。
- **DROID（Distributed Robot Interaction Dataset）**：跨 13 家机构在 564 个真实非实验室生活场景中用统一 Franka 机械臂与立体相机硬件平台采集 7.6 万条（350 小时）多样化操作轨迹，重点攻克“实验室纯色桌面过拟合”难题。
- **AgiBot World / 规模化真机数采工厂**：迈向百万级真机轨迹与双臂灵巧手长程任务（家庭/零售/工业分拣），采用工业化“标准化场景工位 + 多视角标定 + 质检打回”流水线；社区存储标准正从重型 TFRecord 全面转向 **LeRobot 格式（Parquet 存高频状态/动作表 + 硬件加速 MP4 存多视角视频流 + 统一帧索引元数据）**，与 [第 13 章](/books/llm-data/chapters/chapter-13) 多模态视频湖仓存储架构完全合流。

## C.3 Sim-to-Real 仿真合成与 Real-to-Sim 数字孪生管线

为突破真机物理时钟上限，领先团队普遍引入仿真合成管线，将少量真机种子放大 100–1,000 倍：

1. **高并发 GPU 物理仿真器**：基于 **NVIDIA Isaac Lab / Isaac Sim**、**MuJoCo MJX** 或 **Genesis**，在单张 GPU 上并行运行数千个刚体/柔体物理环境实例，实现百万帧/秒级策略 rollout 与自动化任务终态判定（如物体质心落入目标容器且静止超 1 秒）。
2. **系统化域随机化（Domain Randomization）**：为弥合 Sim-to-Real 视觉与动力学鸿沟，数据生成管线必须在可控先验分布内随机化**视觉维度**（纹理材质、环境 HDRI 光照、相机外参微抖、桌面干扰物）与**物理维度**（静/动摩擦系数、物体质量与质心偏移、关节阻尼与控制延迟）。
3. **示范驱动增广与 Real-to-Sim 资产重建**：利用 **MimicGen / DexMimicGen** 将人类 10 条真机示范拆解为“以目标物体为中心的子轨迹段”，在仿真中重新摆放物体位姿并自动插值求解逆运动学，一键生成数千条可验证轨迹；结合 **3D Gaussian Splatting（3DGS）** 与可交互网格重建，把真实工厂/厨房快速扫描为高逼真可仿真数字孪生场景。

## C.4 连续动作 Token 化：如何把物理动作装进 LLM 词表

若要复用原生 VLM 自回归骨架训练 VLA，如何将高频连续动作序列 $\mathbf{a}_{t:t+H} \in \mathbb{R}^{H \times d_a}$ 编码进序列是一道关键数据预处理决策（呼应 [第 2 章](/books/llm-data/chapters/chapter-02) 的分词账本）：

| 编码范式 | 核心机制 | 压缩效率与优缺点 | 代表工作 |
| --- | --- | --- | --- |
| **逐维均匀分箱（Uniform Bin Quantization）** | 将每个自由度按 1%–99% 分位数归一化后离散为 256 个桶，映射至 LLM 词表末段不常用 Token | 实现最简，但在 50 Hz 高频控制下每步占 7–14 tokens，相邻帧高度冗余且易产生阶梯抖动 | RT-2、OpenVLA |
| **频域动作分词（FAST, DCT + BPE）** | 对一段动作块 $\mathbf{a}_{t:t+H}$ 先做离散余弦变换（DCT）剥离高频冗余，再量化并用 BPE 合并常见运动基元 | **压缩率提升 5–10 倍**，可直接用标准自回归交叉熵高效拟合灵巧高频轨迹 | $\pi_0$-FAST（Physical Intelligence） |
| **连续动作专家头（Diffusion / Flow Matching）** | VLM 输出多模态条件隐状态，下游轻量动作头直接预测连续速度场或去噪轨迹，不做离散分箱 | **保留完整亚毫米连续精度与多峰分布**，但数据清洗对异常跳变点与缺失帧更敏感 | $\pi_0$、GR00T N1 |

## C.5 第一视角人类视频预训练与物理一致性清洗红线

除了机器人专属轨迹，互联网与学术界还蕴藏数万小时人类第一视角操作视频（**Ego4D、Ego-Exo4D、Something-Something v2**）。由于人类视频缺乏关节真值标签，前沿数据管线主要通过两条路径榨取其价值：
- **潜动作学习（Latent Action Models, 如 LAPA / Genie）**：从连续视频帧 $(o_t, o_{t+k})$ 中无监督学习离散潜动作码本 $z_t$，先在海量人手操作视频上预训练通用物理演化与操作常识，再用少量真机数据把潜动作对齐到真实机械臂动作空间。
- **视频世界模型与反向动力学（IDM）**：训练动作条件视频生成模型（World Model）作为可微或可控的神经仿真器，或在人手三维骨架估计（HaMeR / MANO）基础上映射灵巧手重定向轨迹。

### VLA 策略训练 vs 物理世界模型（World Model）的数据规格差异

工程立项时必须区分“直接训练具身操作策略（VLA）”与“训练动作条件视频世界模型”的数据吞吐与标注重心：

| 目标范式 | 核心输入/输出监督形态 | 典型采样频率与数据量级 | 核心工程瓶颈 |
| --- | --- | --- | --- |
| **真机/仿真 VLA 策略** | 多视角图 + 本体关节态 + 指令 → 未来 $H$ 步动作块 $\mathbf{a}_{t:t+H}$ | 10–50 Hz；单任务精调 $10^2\text{–}10^3$ 条，通用预训练 $10^5\text{–}10^6$ 条 | 真机动作精度、跨本体对齐、静止死区与异常毛刺清洗 |
| **物理世界模型（World Model）** | 历史视频帧 + 动作/物理条件 → 未来多帧视频演化 $\hat{o}_{t+1:t+K}$ | 5–30 fps；百万至千万级操作/物理交互视频片段（含人类第一视角） | 长视频 <a class="term-ref" href="/books/llm-data/glossary#scene_detection" title="自动识别转场边界将长视频拆解为语义连贯原子镜头片段的过程">镜头切分</a>、物理规律违背过滤（穿模/瞬移）与解码吞吐 |

### 具身轨迹入库 6 项物理一致性清洗红线

与纯文本清洗类似，脏的物理轨迹会直接导致真机危险抖动甚至硬件损坏，入库前必须过以下确定性物理校验：

1. **时间戳对齐核验**：多路相机帧与本体关节状态时间差超过半个控制周期（如 50 Hz 下 $> 10\text{ ms}$）的片段直接剔除或线性重采样。
2. **运动学奇点与尖峰过滤**：检测关节位置超限、一阶速度/二阶加速度（Jerk）超过硬件安全上限的传感器毛刺帧，杜绝将通信丢包跳变喂进模型。
3. **静止死区裁剪（Idle Trimming）**：遥操作员思考停顿、手离手柄导致的连续数秒零位移死区（$\|\Delta \mathbf{a}_t\| < \varepsilon$）必须裁剪或下采样，否则策略在真机推理时会学会“原地卡死不动”。
4. **相机内外参标定检查**：若采集周期内腕部或第三视角相机支架发生碰撞偏移，须通过标定板投影误差重验并按采集批次打标，严防混入未标定偏移批次。
5. **任务终态与指令一致性**：剔除“人类示范中途失败但忘点放弃”的脏轨迹，以及语言指令与实际抓取物体颜色/位置不符的错标样本（可用 VLM 抽检首尾帧对齐核验）。
6. **安全包络与力矩边界审计**：任何含暴力碰撞桌面、夹爪持续过载电流或人类越界干预急停的轨迹段必须切分隔离，绝不混入正向行为克隆训练集。
