# 关于 Tdccccc's Atlas

**Tdccccc's Atlas** 是我的个人技术书库与工程笔记总站，长期沉淀面向一线工程师的体系化技术读物、单篇专题分析与论文精读。

## 写作信条

- **先算清账，再看机制，最后归因**：用显存、带宽、算力与延迟的硬算术建立第一性直觉，拒绝浮在表面的概念堆砌。
- **图文并茂、代码可验证**：关键机制尽量用原创矢量架构图与数据流图呈现，辅以严谨的数学公式与可对照的工程实现。
- **持续扩展的知识图谱**：内容不局限单一方向，目前已上线「数据燃料 × RL 后训练 × 推理底座 × 评测标尺」四部曲——**AI Infra** 主线读物 [《LLM 推理工程：原理与方法》](/books/llm-inference/)、**强化学习** 主线读物 [《LLM 强化学习：原理与后训练实践》](/books/llm-rl/)、**模型与 Agent 评测** 主线读物 [《LLM 与 Agent 评测：原理、基准与工程实践》](/books/llm-eval/)，以及 **数据工程** 主线读物 [《LLM 与 Agent 数据工程：原理、配方与迭代飞轮》](/books/llm-data/)，后续将持续补充单篇工程专题与前沿论文笔记。

## 站内阅读体验

- **全局检索**：按快捷键 `/` 或点击右上角搜索框，可跨全站所有读物与博客进行本地全文搜索。
- **高清配图放大**：正文中的任意机制 SVG 图支持点击全屏预览、滚轮缩放、拖拽平移及新标签页打开原图。
- **开源共享**：本站技术内容默认遵循 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 协议共享；配套开源代码与工程脚本见 [GitHub @tdccccc](https://github.com/tdccccc)。
